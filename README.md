# Leopold — сайт панорамного ресторана

Одностраничный сайт ресторана «Леопольд / Leopold» (Бишкек, ЦУМ, 8 этаж).
Структура повторяет референс bosca.kg, код и дизайн — собственные.

## Запуск

Статический сайт, сборка не нужна:

```bash
python3 -m http.server 8095
```

или в Docker (nginx, gzip, кеширование ассетов):

```bash
docker build -t leopold-site . && docker run -p 8095:80 leopold-site
```

## Структура

```
index.html            разметка, SEO-мета, JSON-LD Restaurant, SVG-иконки
css/styles.css        все стили, адаптив 1100 / 900 / 640 px, prefers-reduced-motion
js/main.js            интерактивность без зависимостей
assets/img/*.jpg      фото ресторана из карточки 2ГИС, кадрированы и сжаты; og.jpg для соцсетей
404.html, robots.txt, site.webmanifest, favicon.svg, nginx.conf, Dockerfile
```

## Секции

Hero со слайдшоу → бегущая строка → О ресторане → цифры → Почему Leopold →
меню с фильтром → фирменные блюда (горизонтальный скролл) → Панорама (день/закат/ночь)
→ Банкеты → Галерея с лайтбоксом → Отзывы → Бронирование → Контакты с картой → подвал.

## Что работает

- статус «Открыто / Закрыто» и часы по времени Бишкека (Asia/Bishkek);
- панорама сама выбирает день / закат / ночь по текущему часу в Бишкеке;
- форма брони: валидация, маска +996, слоты времени 11:00–22:00 (прошедшие на сегодня скрыты),
  отправка — открывает WhatsApp +996 998 000 333 с готовым текстом заявки;
- кнопки «Обсудить мероприятие», «Столик у окна», пункты банкетов предзаполняют форму;
- меню с фильтром и клавиатурной навигацией по вкладкам, лайтбокс (клавиши ← → Esc, свайпы);
- мобильное меню, кастомный курсор и магнитные кнопки только на устройствах с мышью.

## Что заменить перед публикацией

- **Фото** — взяты из карточки ресторана в 2ГИС (снимки владельца и гостей, без лиц посетителей).
  Это фото с телефонов; для продакшена лучше получить у ресторана профессиональную съёмку
  и разрешение на использование. Заменить просто: файлы в `assets/img/` с теми же именами.
- **Меню и цены** — блюда подобраны под фото из 2ГИС, названия и цены ориентировочные
  (кроме среднего чека ~2000 сом). Сверьте с актуальным меню в `index.html`, блок `#menu`.
- **Домен** — после выбора домена пропишите абсолютные URL в `og:image`, добавьте
  `<link rel="canonical">` и `sitemap.xml`.

и профиль Instagram @leopold.rest.
